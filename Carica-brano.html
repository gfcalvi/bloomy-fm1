BLOOMY · STRUMENTI 1.5

Carica un brano in uno slot.

Scegli il file e dove metterlo. Gli altri quattro slot, la libreria preset/kit e i campioni esistenti vengono conservati. Se mancano campioni presenti nel file, puoi aggiungerli nella stessa operazione senza sostituire quelli già caricati.

Sull’FM-1 premi SAVE per salvare il lavoro aperto e ferma PLAY. Poi collega il dispositivo via USB. Serve Bloomy 1.0 o 1.0.1.

1 · Scegli il brano

.bloomyproject, .loom8, .txt, .rfm1state o .fm1save. Non serve convertirlo prima.

2 · Controlla e carica

Puoi salvare il backup completo prima di continuare. Durante la conferma non cambiare progetto o dati sull’FM-1.

Scegli un file per iniziare.

Dopo il caricamento: sull’FM-1 apri HOME → SEL → LOAD PROJECT e scegli lo slot indicato. Se hai sostituito il progetto già aperto, il dispositivo lo ricarica.

Vuoi sostituire l’intero archivio? Usa Backup → Ripristino completo. Per preparare un set di tre brani usa Set e slot. I file restano nel browser, senza upload a un server.
