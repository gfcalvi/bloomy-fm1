Bloomy · Set e slot

Per caricare un solo brano sul dispositivo usa Carica brano: conserva automaticamente gli altri quattro slot.

I tuoi progetti, fino a cinque alla volta. Estrai gli slot da un backup e prepara il prossimo set per Bloomy 1.1.1. Elaborazione sul dispositivo, senza rete né MIDI.

1 · Estrai dal backup

Un file .bloomyproject per ogni slot, anche vuoto. Ogni file porta con sé il banco campioni e la libreria preset/kit originali.

2 · Componi il tuo set

Carica da uno a cinque progetti nelle posizioni desiderate. Le posizioni senza file rimangono vuote nel backup. Usa «Svuota slot» per rimuovere un progetto.

I suoni delle tracce restano nei progetti. La libreria comune sarà quella disponibile per richiamare preset/kit. Banchi campioni diversi nei progetti non vuoti bloccano l’unione: questa versione non rimappa i campioni.

Uso offline su Mac e iOS

Mac: usa la suite in Chrome. Su iPhone apri la suite da HTTPS in MIDIWeb Browser e usa Make Available Offline; l’anteprima nell’app File può non eseguire l’utility. Il pacchetto non è un’app iOS installabile. Apertura e salvataggio su iOS sono da collaudare.

Prima del backup premi SAVE sulla macchina. Per il restore usa il percorso Backup di Bloomy: il ripristino sostituisce i cinque slot, la libreria e il banco presenti nel file. Conserva un backup della macchina prima di procedere.

Compatibilità software: progetti formato 21–23, libreria 13–14; Bloomy 1.1.1 usa 23/14. Gli slot sono copiati senza modificare i dati musicali compressi. La verifica CRC non sostituisce il collaudo musicale e del restore sull’hardware.
Apri un backup per estrarre i progetti, oppure carica da uno a cinque file progetto.
