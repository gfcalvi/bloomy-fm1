# Bloomy 1.1.0 · candidato a cinque slot

Apri https://gfcalvi.github.io/bloomy-fm1/candidati/1.1.0/ in Chrome (Mac) o MIDIWeb Browser (iPhone). Su iPhone: Make Available Offline, poi verifica la copia senza rete. Nessun account e nessun Mac da lasciare acceso.

Il collaudo su FM-1 fisico e iPhone di questa versione è ancora da eseguire. Guida-cinque-slot.pdf descrive la procedura e le opzioni. Non installare il file firmware con l’installatore pubblico della 1.0.1: il banco campioni cambia mappa.

Percorso: SAVE e STOP → Installazione → lascia vuoto il campo backup per leggere direttamente FM-1 (oppure scegli un file già salvato) → copia di sicurezza scaricabile facoltativamente → conferma installazione e successivo Restore con SEL sul dispositivo → attendi rilettura verificata.

Cinque slot indipendenti, un progetto attivo. Banco campioni 104 KiB; se il banco attuale non entra, il flash non comincia. Nessun campione viene ridotto o eliminato. Per tornare a tre slot, usa Ritorno a tre slot, con lettura diretta o file salvato. Per conservare i progetti 4/5 dopo il ritorno, scaricane i file separati.

Bloomy.html contiene tutte le funzioni offline. Il PDF, il core RemoteFM1, l’emulatore e gli archivi si scaricano separatamente. Il core bloomy_s5-1.1.0.rfm1 è per RemoteFM1; Bloomy-1.1.0.fwsc è per hardware, non sono song.

Sul Mac puoi anche aprire Bloomy.html dalla cartella estratta. L’emulatore nella cartella emu richiede HTTPS o localhost; la copia online è al percorso emu/ del candidato. Usa un archivio browser separato da quello della 1.0.1, che conserva i suoi dati.

Il manuale completo della 1.0.1 resta valido per le funzioni musicali; la guida inclusa descrive le differenze relative a cinque slot e migrazione. Il candidato non sostituisce ancora la release stabile.
