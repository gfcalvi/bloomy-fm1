Bloomy · Project Picker

I tuoi progetti, fino a tre alla volta. Estrai gli slot da un backup e prepara il prossimo set per Bloomy 1.0. Elaborazione sul dispositivo, senza rete né MIDI.

1 · Estrai dal backup

Un file .bloomyproject per ogni slot, anche vuoto. Ogni file porta con sé il banco campioni e la libreria preset/kit originali.

2 · Componi il tuo set

Carica da uno a tre progetti nelle posizioni desiderate. Le posizioni senza file rimangono vuote nel backup. Usa «Svuota slot» per rimuovere un progetto.

I suoni delle tracce restano nei progetti. La libreria comune sarà quella disponibile per richiamare preset/kit. Banchi campioni diversi nei progetti non vuoti bloccano l’unione: questa versione non rimappa i campioni.

Uso offline su Mac e iOS

Mac: apri questo HTML nel browser. iPhone/iPad: aprilo in un browser o contenitore che esegua HTML locale e consenta di aprire e salvare file; l’anteprima nell’app File può non eseguire l’utility. Il pacchetto non è un’app iOS installabile. Apertura e salvataggio su iOS sono da collaudare.

Prima del backup premi SAVE sulla macchina. Per il restore usa il percorso Backup di Bloomy: il ripristino sostituisce i tre slot, la libreria e il banco presenti nel file. Conserva un backup della macchina prima di procedere.

Compatibilità software: progetti formato 21–23, libreria 13–14; Bloomy 1.0 usa 23/14. Gli slot sono copiati senza modificare i dati musicali compressi. La verifica CRC non sostituisce il collaudo musicale e del restore sull’hardware.
Apri un backup per estrarre i progetti, oppure carica da uno a tre file progetto.
